# 🇮🇳 Indian Census 2011 Dashboard (Excel)

An interactive Microsoft Excel dashboard built using the **Indian Census 2011** dataset. This project demonstrates data analysis and visualization using **Pivot Tables, Pivot Charts, and Slicers** to explore key demographic indicators across Indian states and districts.

---

## 📊 Dashboard Preview

> Replace the image below with your dashboard screenshot named **dashboard.png**.

![Dashboard Preview](dashboard.png)

---

## 🚀 Project Overview

This dashboard provides an interactive analysis of the Indian Census 2011 dataset, allowing users to explore state-wise and district-wise demographic statistics through dynamic filters and charts.

The dashboard focuses on:

- 📈 Population Growth
- 📚 Literacy Rate
- 👨‍👩‍👧‍👦 Sex Ratio
- 🗺️ State-wise Analysis
- 🏙️ District-wise Analysis

---

## 📂 Dataset

The dataset contains the following columns:

| Column | Description |
|---------|-------------|
| District | Name of the district |
| State | Name of the state/UT |
| Growth | Population growth rate (%) |
| Sex_Ratio | Number of females per 1000 males |
| Literacy | Literacy rate (%) |

---

## ✨ Dashboard Features

- Interactive **State** and **District** slicers
- State-wise average literacy analysis
- State-wise average population growth analysis
- District-wise growth visualization
- Top states based on literacy rate
- Dynamic Pivot Charts
- Clean and interactive dashboard layout

---

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Excel Formatting

---

## 📈 Key Insights

- Compare literacy rates across different states.
- Analyze average population growth by state.
- Filter results dynamically using slicers.
- Identify states with higher literacy rates.
- Explore district-level demographic trends.
