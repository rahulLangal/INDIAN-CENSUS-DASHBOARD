# 🇮🇳 Indian Census 2011 Dashboard (Microsoft Excel)

An interactive Excel dashboard built using the **Indian Census 2011** dataset. The dashboard provides insights into key demographic indicators such as **Literacy Rate**, **Population Growth**, and **Sex Ratio** using Pivot Tables, Pivot Charts, and Slicers.

---

## 📊 Dashboard Preview

![Dashboard Preview](dashboard.png)

---

## 📌 Project Overview

This project demonstrates how Microsoft Excel can be used to create an interactive dashboard for demographic data analysis. Users can filter the dashboard using slicers to analyze data at both the **State** and **District** levels.

---

## 📂 Dataset

The dataset contains the following columns:

- District
- State
- Growth
- Sex_Ratio
- Literacy

---

## ✨ Features

- Interactive State and District slicers
- State-wise Literacy Analysis
- State-wise Population Growth Analysis
- District-wise Growth Analysis
- Top States by Literacy

## 🚀 How to Use

1. Download or clone this repository.
2. Open **Indian_Census_2011_Dashboard.xlsx** in Microsoft Excel.
3. Enable editing if prompted.
4. Use the **State** and **District** slicers to interact with the dashboard.
